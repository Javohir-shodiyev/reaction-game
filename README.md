# Reaction Game

A Python reaction and mental-math game where you solve randomly generated challenges under time limits.

## Features

* Time-based challenges
* Mental-math questions
* Increasing difficulty
* Lives and scoring system
* Streak bonuses
* Randomly generated tasks

## How to Run

Run the Python file in a terminal and follow the instructions.

## Built With

* Python
* `random`
* `time`
